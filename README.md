# PowerBI-Ecommerce-Data-Analysis
E-commerce Data Analysis dashboard developed using Microsoft Power BI to analyze customer behavior, pricing, promotions, traffic, sales, and business KPIs.

##  Project Overview

This project is an **E-commerce Data Analysis Dashboard** developed using **Microsoft Power BI**.

The objective of this project is to analyze customer behavior and e-commerce activity and present meaningful business insights through interactive dashboards and reports.

The analysis focuses on areas such as:

* Key Business KPIs
* Pricing and Promotions
* Customer and Product Activity
* Search Behavior
* Sales and Revenue Analysis
* Traffic and Channel Analysis
* Impact of Special Promotions
* Pricing fluctuations and their effect on sales

---

##  Project Objective

The main objective of this project is to transform raw e-commerce data into meaningful insights using Power BI.

The project includes:

* Data cleaning and preparation
* Data transformation
* Data modeling
* KPI creation
* Interactive dashboard development
* Business analysis
* Insight generation

The final dashboard is designed to help users understand customer behavior, product activity, pricing, promotions, and sales performance.

---

##  Dataset

The project uses two main datasets provided for the analysis.

### 1. Sales_Data_Ecommerce.csv

This is the main customer-behavior dataset.

It contains information such as:

* User ID
* Event Date
* Day of Week
* Channel
* Event Time
* Event Hour
* Event Timezone
* Event Type
* Product ID
* Category ID
* Category
* Sub-category
* Brand
* Price
* User Session
* State
* User Score

The dataset contains customer events such as **view, cart, and purchase** activities.

### 2. Promotion.csv.xlsx

This dataset contains information about special product promotions.

It includes:

* Promotion ID
* Promotion Date
* Discount
* Product ID

##  Business Questions

The project analyzes several business questions, including:

1. How does price vary by brand, category, time, and channel?
2. Does traffic vary by day, time, and channel?
3. What are the key metrics such as revenue, potential revenue, products, and categories?
4. What is the activity by brand and category?
5. What is the search behavior by brand and category?
6. What is the effect of special promotions?
7. How do pricing fluctuations affect sales?

The Power BI dashboard provides an interactive view of the e-commerce data and allows users to analyze different business dimensions.

The dashboard focuses on:

### Customer & Product Activity

##  How to Use This Project

1. Download the `Ecommerce_Data_Analysis.pbix` file.
2. Open it using **Microsoft Power BI Desktop**.
3. If required, update the data-source paths for the CSV/Excel files.
4. Refresh the data.
5. Explore the interactive dashboards and reports.
